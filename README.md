# Внедрение информационной системы управления заказами

## Название и назначение проекта

Проект внедрения информационной системы учёта и обработки заказов клиентов
для торгового предприятия. Цель проекта — заменить разрозненные таблицы и
бумажные журналы единой системой, обеспечить прозрачный статус заказов и
формирование отчётности для руководства.

Репозиторий хранит всю проектную информацию: требования, архитектуру,
конфигурации, тестовые материалы и управленческие документы, а также историю
их изменений.

## Структура папок

```
project_IS/
├── docs/           # проектная документация (требования, архитектура)
│   └── requirements.md
├── src/            # код / конфигурации
│   └── config.example.yaml
├── tests/          # тестовые материалы
│   └── test_plan.md
├── management/     # управленческая информация
│   └── project_plan.md
└── README.md       # описание проекта
```

## Как запустить / использовать

1. Клонировать репозиторий: `git clone <URL> project_IS`.
2. Прочитать требования в `docs/requirements.md` и план проекта в
   `management/project_plan.md`.
3. Скопировать `src/config.example.yaml` в `src/config.yaml` и задать параметры
   окружения.
4. Тестовые сценарии из `tests/test_plan.md` выполнять после каждого
   обновления конфигурации.
5. Изменения вносить отдельными коммитами с осмысленными сообщениями.
