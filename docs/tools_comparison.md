# Сравнение инструментов репозитория проекта внедрения

## Сравнительная таблица

| Критерий | SAP Cloud ALM | 1С:Хранилище конфигурации | Git + GitLab |
|---|---|---|---|
| Категория | Репозиторий проекта (ALM) для SAP | Встроенный репозиторий групповой разработки 1С | Универсальная система контроля версий (VCS) |
| Что хранит | Задачи, требования, сценарии тестов, ход внедрения; код — в связанных системах SAP | Объекты конфигурации 1С (формы, модули, макеты, справочники) | Любые текстовые и бинарные файлы: код, документы, конфигурации |
| Версионирование | Версии проектных артефактов и статусов, привязка к фазам SAP Activate; версий исходного кода нет | Нумерованные версии конфигурации, история по каждому объекту, сравнение и откат к версии | Полная история коммитов, ветки, теги, откат, сравнение любых версий |
| Разграничение доступа | Роли и авторизации SAP, доступ по проектам и областям | Пользователи хранилища с правами «чтение / захват объектов / изменение версий» | Роли Guest / Reporter / Developer / Maintainer / Owner, защищённые ветки, merge request с утверждением |
| Работа с конфликтами | Конфликтов правок кода нет — управляется рабочий процесс и статусы задач | Пессимистичная блокировка: объект «захватывается» одним разработчиком; при слиянии версий — сравнение/объединение конфигураций | Оптимистичная модель: параллельные правки, слияние (merge/rebase), конфликты решаются вручную в слитом файле |
| Стоимость владения | Подписка SaaS (по числу пользователей и тарифу SAP), включена в часть SAP-контрактов | Лицензия платформы 1С + лицензии клиентов хранилища; отдельного ПО не требуется | Git бесплатен; GitLab CE бесплатен (затраты на сервер и администрирование), GitLab EE/SaaS — по подписке |
| Сложность внедрения и обучения | Средняя/высокая: нужны SAP-ландшафт, настройка методологии и ролей, обучение консультантов | Низкая для 1С-команды: встроено в Конфигуратор; обучение за 1–2 дня | Средняя: настройка сервера и процессов; для новичков сложны ветки и слияние, зато много материалов и сообществ |

## Вывод

**SAP Cloud ALM** подходит для средних и крупных проектов внедрения SAP (S/4HANA, облачные решения) с большой распределённой командой, где нужны управление требованиями, тестированием и ходом проекта в одном месте. Риски: привязка к экосистеме SAP, не заменяет систему контроля версий кода, затраты на подписку и обучение, зависимость от поставщика.

**1С:Хранилище конфигурации** подходит для малых и средних проектов на платформе 1С (команда 2–15 разработчиков). Риски: работает только с объектами конфигурации 1С, блокировки замедляют работу при большом числе разработчиков (захваченный объект «забыт» — другие простаивают), слабая поддержка ветвления, нет полноценных процессов code review и CI без дополнительных средств.

**Git + GitLab** подходит для проектов любого масштаба — от учебного до корпоративного, особенно со смешанным составом артефактов (код, документы, конфигурации) и распределённой командой. Риски: порог входа для неопытных участников, возможные конфликты слияния при отсутствии регламента, необходимость администрирования сервера и резервного копирования, бинарные файлы хранятся неэффективно.

**Рекомендация для данного проекта:** Git + GitLab как основной репозиторий проектных артефактов; при разработке на 1С — дополнительно хранилище конфигурации для объектов конфигурации с периодической выгрузкой версий в Git.
