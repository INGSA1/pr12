# Архитектура информационной системы

## Обзор

Система построена по трёхзвенной схеме: клиентский интерфейс, сервер приложений
(бизнес-логика обработки заказов) и база данных.

```
[Пользователь] -> [Веб-интерфейс] -> [Сервер приложений] -> [База данных]
                                            |
                                            +-> [Модуль отчётности]
```

## Компоненты

| Компонент          | Назначение                                        |
|--------------------|---------------------------------------------------|
| Веб-интерфейс      | Ввод и просмотр заказов, смена статусов           |
| Сервер приложений  | Правила обработки заказов, контроль статусов      |
| База данных        | Хранение заказов, клиентов и справочников         |
| Модуль отчётности  | Отчёты по заказам за период (FR-03)               |

## Интеграции

Выгрузка отгруженных заказов в бухгалтерскую систему — в формате CSV по
расписанию (раз в сутки).
